# 小型办公平面布局

默认布局为 `small_office_v1`，10×10米，六个功能房间及前厅、走廊。
房间几何来自本项目自行设计，参考导航项目的空间组织，并非按比例复制某栋实测建筑。

## 参考与设计取舍

- [Open-RMF Office World](https://github.com/open-rmf/rmf_demos#office-world) 包含办公导航、饮料服务点、门和通道；其
  [office.building.yaml固定版本](https://github.com/open-rmf/rmf_demos/blob/cbe371a884be8f7ba88edf7fbed9b19171e7fa0f/rmf_demos_maps/maps/office/office.building.yaml)
  提供实际门、通道和pantry/lounge等目的地的组织示例。本图采用公共通道连接功能房间。
- [Arena-Rosnav的室内场景文档](https://docs.arena-rosnav.org/en/latest/arena_simulation_setup/worlds/) 提供
  `office_1` 办公场景及区域多边形、墙和门的独立描述。本图同步保存区域用途、门洞与几何，而不是只给矩形块命名。
- [TurtleBot3官方仿真](https://emanual.robotis.com/docs/en/platform/turtlebot3/simulation/) 区分简单障碍场与House室内场景。
  本轮选择用户确认的办公用途，使用明确房间与公共动线；继续保留仅墙体障碍的实验范围。

设计上，前厅用于接待和分流，三间办公室均有独立公共入口，不需要穿过其他办公室。
会议室一门通前厅、一门通主走廊，访客可直接进入，也提供一条经公共会议空间的备选路线。
茶水间与卫生间集中于后侧，门开向走廊。左右分隔错位、房间大小按用途区分，公共空间形成L形。
前厅17.4平方米，走廊净宽1.50米；普通房门1.00米，前厅到走廊为1.60米开放口。

外侧主入口只标注其关闭位置，仍由封闭场地边界负责碰撞，不允许机器人离开10×10计算区域。
室内门洞保持常开，没有移动门扇、家具或其他额外障碍。

## 训练和兼容

默认 `configs/mobile_rooms_hybrid.yaml` 使用新图；此前的混合六房间配置完整保存在
`configs/mobile_rooms_hybrid_six.yaml`。旧离散六房间、四房间和E4/E5/E6配置保留。
57维单帧、20帧1140维历史、混合动作、速度、1200步和奖励系数保持相同；地图摘要区分模型与题库。
气源和机器人每局在全部有效区域独立随机采样，包括前厅、走廊，距离/安全间距条件沿用。
同区域/跨区域统计仍按稳定区域ID判断，reception与corridor分别计为独立区域。

```powershell
python scripts/visualize_room_layout.py
# 旧六房间混合模型显式使用归档配置
python scripts/evaluate_mobile_whisker_ppo.py --config configs/mobile_rooms_hybrid_six.yaml --model-path <旧模型路径>
```

羽流仍用现有墙体反射与视线遮挡近似，不求解办公室压力、空调通风或回流。
新布局需重新训练；短训只验收接口连通，不能用其成功率判断办公场景下的搜索能力。
